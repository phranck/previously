A Raspberry Pi that boots into NeXTSTEP

It starts straight into a NeXT machine under the Previous emulator, with no desktop behind it and no login to get past. What configures it is a web admin built to look like the machine it configures, and this page is drawn with that admin's own windows and fields.

Install it

On a Raspberry Pi 5 running a fresh Raspberry Pi OS Lite, updated, with a network. Paste this and let it finish:

curl -fsSL https://previously.layered.work/install.sh | bash

It fetches the NeXTSTEP disk image, installs the emulator and the admin tool, and takes the first console. When it is done it says where the admin is and how to read the token it asks for once.

What it does to the machine

  • Installs the Previous emulator from its own archive, and the admin tool as a Debian package.
  • Starts NeXTSTEP on the first console at boot. SSH stays the way in.
  • Writes down everything it changed, so one flag puts all of it back.

Then

The admin answers at http://<your-pi>.local:2342, and the source is on GitHub.
